# 🌙 CohenDad - Your Mystical AI Guide

An AI-powered numerology and astrology-based oracle app, offering personalized prophecies and insights for users based on their birth data.

## ✨ Features

- 🔮 **Tarot Readings**: Daily cards, 3-card spreads, Celtic Cross, and more
- ⭐ **Astrology**: Natal chart analysis, transits, and cosmic insights
- 🔢 **Numerology**: Life path numbers and personal calculations
- 💭 **Dream Journal**: Record and analyze your dreams with AI
- 🤖 **AI Chat**: Conversational guidance with CohenDad (premium)
- 📊 **Deep Insights**: Weekly reports and personalized analysis

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Copy environment file
cp .env.example .env

# Add your credentials to .env
# (Firebase, OpenAI, RevenueCat keys)

# Start development server
npm start

# Run on iOS
npm run ios

# Run on Android
npm run android
```

- **Backend**: Firebase (Auth, Firestore, Cloud Functions)
- **AI**: OpenAI GPT-4
- **Payments**: RevenueCat
